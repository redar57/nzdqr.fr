Le Lion
A l'endroit : interne

La classe, la promo
Le nom traditionnel de la classe est inscrit sur le khâlot, souvent sur une bande de tissu ajoutée (une pour les bizuths, deux pour les khârrés, trois pour les khûbes). La promo est indiqué par un nombre.

Renversé : non bizuthé

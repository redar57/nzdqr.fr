Enquêtes

Attention, il s'agit d'une page sérieuse ! Cette page est dédiée aux enquêtes auprès des visiteurs de ce site, pour en améliorer le contenu. La fréquence des enquêtes n'est pas vraiment déterminée... (Pas comme pour les sondages.)

Enquête n°1

Le sujet de cette première enquête était l'intégrationde la classe PSI* au sein de ce site. 
  1. Pensez vous que ce site (W3MP) devrait également représenter la classe PSI* de Camille Guérin (rappel : seules les classe MP et MP* le sont pour le moment) ?

    2. (Oui / Non)
     
  2. Le cas échéant, pensez vous que le titre W3MP doit changer ?

    3. (Oui / Non)
     
  3. Si oui, quel nom proposez-vous (attention, c'est sérieux...) ?

Apparemment, ce qui ressort assez fortement, c'est la volonté de créer un site plus "ouvert" à toutes les classes de Taupe. Non seulement les PSI*, mais aussi les PC, PC* et les Hypos (MPSI, PCSI) devraient être aussi représentés. Y'a peut-être moyen de faire quelquechose, grâce aux récentes évolutions de Citeweb, notre hébergeur (cf. l'info sur le sommaire datée du 30/03/2000). Vous pouvez aussi nous écrire pour nous envoyer vos propositions !

Sinon, pour ce qui est du titre, il est probable que W3MP restera le nom officiel, même si un sous-titre du genre le Site de la Taupe Pictave sera ajouté par la suite...

(En fait, c'est plus pour des raisons techniques qu'autre chose que le titre est conservé : il est difficile de garder une adresse (URL) contenant "w3mp" si ce nom n'apparaît nulle part. Et puis maintenant que le site est un petit peu connu, changer d'adresse n'est pas une bonne idée...)

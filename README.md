# nzdqr.fr

Personal website hosted on GitHub Pages with a custom domain (`nzdqr.fr`).

## Overview

* **Frontend**: HTML5, CSS
* **Hosting**: GitHub Pages
* **Domain & DNS**: IONOS
* **Mail Setup**: Custom routing configured via Zoho Mail

## Project Structure

```text
.
├── index.html      # Main landing page
├── 404.html        # Custom "not found" page
├── style.css       # Styles
├── sigma.png       # Browser tab icon
├── CNAME           # Custom domain for GitHub Pages
└── README.md
```

nzdqr.com, nzdqr.info, nzdqr.online and nzdqr.store redirect here.

# nzdqr.fr

Personal website hosted on GitHub Pages with a custom domain (`nzdqr.fr`), styled as a small retro desktop: icons, draggable windows, a start menu and switchable wallpapers.

## Overview

* **Frontend**: plain HTML, CSS and a bit of vanilla JS, no framework
* **Hosting**: GitHub Pages
* **Domain & DNS**: IONOS
* **Mail Setup**: Custom routing configured via Zoho Mail

## Project Structure

```text
.
├── index.html      # Main landing page
├── 404.html        # Custom "not found" page
├── style.css       # Styles and wallpapers
├── script.js       # Windows, start menu, quotes, wallpaper picker
├── sigma.png       # Browser tab icon
├── CNAME           # Custom domain for GitHub Pages
└── README.md
```

nzdqr.com, nzdqr.info, nzdqr.online and nzdqr.store redirect here.
